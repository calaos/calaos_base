## ⚠️⭐ LE COMPTE DE JETONS JANSSON TOMBERA À **2**, PAS À **0** — et ce n'est PAS un échec de clôture

**Consigné au merge d'[`E4.1s`](E4.1s.md) (2026-09-01), mesuré, pour que personne ne croie à un
ticket raté.**

La convention de comptage de la série (écrite dans `ORCHESTRATION.md`, « la convention de comptage
des jetons jansson ») cherche `\b(json_\w*|jansson\w*)\b` dans les fichiers suivis de `src/`,
commentaires, littéraux chaîne et `#include` blanchis. **Ce motif attrape deux occurrences qui
n'ont RIEN à voir avec jansson** :

```cpp
/* src/bin/calaos_server/WebSocket.cpp:328-329 */
string json_body = error_response.dump(-1, ' ', true, Json::error_handler_t::replace);
string res = buildHttpResponse(http_status_line, headers, json_body);
```

`json_body` est une **`std::string` locale**, produite par un `dump()` **nlohmann**. Le motif la
prend pour un symbole jansson parce qu'elle commence par `json_`. ⇒ **2 faux positifs, dans un seul
fichier, sur une seule expression.**

**Le compte, décomposé à la tête de merge d'E4.1s (`d818a391`) — total `src/` : 110** :

| `JsonApi.cpp` | 6 | **E4.6d** — c'est `janssonScenarioPayloadBridge()`, le pont vers `Scenario::toJson()` |

⇒ Après E4.6b + E4.6d (63) **et** ce ticket (45), la convention rendra **2**. ⛔ **Ne « corrige » pas
`WebSocket.cpp` pour faire tomber le chiffre à zéro** : renommer une variable locale pour satisfaire
un `grep` est un changement de code sans objet, et le motif resterait faux pour le prochain qui
l'écrit.

ℹ️ **Le critère d'acceptation 1 ci-dessous n'est PAS concerné** : il cherche `json_t\|jansson`, et
`json_body` ne correspond à **ni l'un ni l'autre**. **Il doit donc bien rendre ZÉRO ligne.** Ce sont
deux mesures différentes, et seule celle de la convention voit les deux faux positifs. **Dis-le dans
ton rapport de clôture**, sinon quelqu'un lira « 2 » et croira à un échec.

## Pièges de bascule communs à toute la série (mesurés par E4.0, ne pas redécouvrir)

- **Tout part en chaîne** : 32 `json_string`, **zéro** `json_real`/`json_integer` dans
  `JsonApi.cpp` ; seul `eventlog` émet de vrais entiers. **Un `int` devenu nombre JSON est une
  rupture de contrat** — l'oracle des tests est **type-strict** (`3 != "3"`).
- **`Utils::to_string(double)`** est un `ostringstream` nu (`1234.56789` → `"1234.57"`,
  `123456789.0` → `"1.23457e+08"`), épinglé par des goldens. **Ne le « corrige » pas.**
- **Clé absente ≠ `null`** : `buildJsonIO` **omet** une clé absente. Épinglé.
- **`Params` est un `std::map`** → itération **alphabétique**, jamais d'insertion.
- **Les trois invariants d'émission** (E4.1b) : clés triées · `ensure_ascii = true` ·
  `error_handler_t::replace`. Les trois vont ensemble sur chaque `dump()`.
