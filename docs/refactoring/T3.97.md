# T3.97 — trois sites post-authentification republient une valeur du corps d'une requête, dont un à un niveau imprimé par défaut

**Statut** : 📋 · **Type** : fix (hygiène de journal) + test · **Phase** : 3 · **Dépend de** : —
**Origine** : les deux premiers sites sont **mesurés par la revue de merge** de
[`T3.92`](T3.92.md), qui a invalidé l'affirmation « aucun autre site ne republie un corps de l'API
JSON » ; le troisième a été trouvé en écrivant [`T3.93`](T3.93.md). **Vérifiés aux sources et dans
un journal réel par [`T3.93`](T3.93.md), et fichés sans être corrigés.**
**Finding** : `F-HTTPIN-5`.

Les numéros de ligne sont ceux de `master` = `ac01db87` et ils périment.

---

## 1. Les trois sites

| Site | Macro | Niveau | Ce qui sort | Authentifié ? |
|---|---|---|---|---|
| ⛔ `JsonApi.cpp:1318` (`decodeSetState`) | `cWarningDom("network")` | **3** | la **valeur de `set_state` verbatim**, entre guillemets | ✅ oui |
| `JsonApiHandlerHttp.cpp:1314` | `cDebugDom("network")` | 5 | `jsonParam["pic_uid"]` | ✅ oui |
| ⚠️ `JsonApi.cpp:2487` (`buildJsonSetTimerange`) | ⛔ **`cout` brut** | **hors filtre** | `p.toString()` de **chaque plage horaire** envoyée par le client | ✅ oui |

### 1.1 ⛔ Le premier est imprimé sur un boîtier neuf

```cpp
cWarningDom("network") << "set_state refused for io " << jParam["id"]
                       << ": the value ends on its separator (\""
                       << jParam["value"] << "\"), which is a command "
                       << "with no argument";
```

Le repli de `Logger::maxLevelPrintable()` est `LOG_LEVEL_INFO` = 4, donc WARNING **est imprimé sans
que personne n'ait rien allumé**. ⭐ **Mesuré, pas déduit** : la suite `core/IncomingLogStockLevel_test`
livrée par [`T3.93`](T3.93.md) le lit dans le sous-ensemble « lignes d'un boîtier neuf » de son
journal :

```
[WRN] network (JsonApi.cpp:1318) set_state refused for io io_chaine_de_ce_test: the value ends on
its separator ("etat "), which is a command with no argument
```

`set_state` écrit **n'importe quelle** valeur de **n'importe quel** IO. C'est la même forme que le
`set_param` que [`T3.92`](T3.92.md) a fermé — le mot « password » y est la **valeur** de `param`, le
secret voyage sous `value` — sauf qu'ici la valeur sort **une ligne plus bas dans l'échelle des
niveaux**, et **après** le réducteur, donc hors de sa portée.

### 1.2 Le deuxième est à DEBUG

```cpp
cDebugDom("network") << "Picture " << jsonParam["pic_uid"] << " not found";
```

`pic_uid` est un identifiant de photo d'événement, résolu par `resolveEventPicture()`. Le chemin
court **après** `checkCredentials()`. Niveau 5 ⇒ **pas imprimé** sur un boîtier neuf.

### 1.3 ⚠️ Le troisième contourne le journal entièrement

```cpp
cout << "Adding timerange: " << p.toString() << endl;
```

Ce n'est pas une macro de journal : c'est un `cout` **brut**, donc **aucun niveau ne le filtre** et
`debug_level` n'a aucune prise dessus. Il republie l'objet décodé de **chaque** plage horaire qu'un
client envoie dans un `set_timerange`. Le contenu (jour, heures) n'est pas un secret, mais
⛔ **une écriture non filtrée sur `stdout` dans un chemin d'API est une classe à elle seule** : ce
qui la traverse demain n'est pas décidé par ce site.

## 2. ⭐ Ce que la mesure dit déjà, et ce qui reste à trancher

- **Le premier est le seul qui compte pour la sévérité** : niveau imprimé par défaut, valeur
  arbitraire choisie par le client, chemin authentifié.
- ⚠️ **L'arbitrage n'est pas évident** : cette ligne existe parce que la valeur *se termine sur son
  séparateur*, et l'opérateur a besoin de **voir** la valeur fautive pour comprendre. La forme qui
  garde les deux est celle qu'a retenue [`T3.92`](T3.92.md) : publier **la forme** (longueur,
  dernier octet nommé) et non les octets.
- ⚠️ **Et une incohérence de traitement, relevée par la revue de `T3.92` et toujours vraie** : le
  réducteur nettoie les octets de commande d'un **nom** de clef pour qu'il ne forge pas une ligne,
  mais le site voisin sort `skey` **brut** à ERROR.

## 3. ⛔ Ce que ce ticket ne dit pas

- Il ne prétend **pas** qu'un secret sort aujourd'hui par le premier site : il dit qu'une valeur
  **arbitraire** du client y sort, à un niveau imprimé par défaut, et que rien ne l'en empêche.
- Le harnais existe et il est **neuf** : `tests/core/IncomingLogStockLevel_test.cpp` atteint déjà le
  premier site par une vraie requête sur la socket, et son foin est déjà « ce qu'un boîtier neuf
  imprime ». Un cas de fuite s'y écrit sans nouveau harnais.
- ⛔ **Le périmètre du corps d'une requête *avant* authentification est ailleurs**
  ([`T3.92`](T3.92.md), fermé) ; celui du filet sur les sept familles entrantes aussi
  ([`T3.93`](T3.93.md), fermé).
