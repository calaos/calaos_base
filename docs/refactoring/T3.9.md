`referenced()`, sans vérifier le pid. Après un `uv_spawn` raté le pid reste 0 →
`kill(0, SIGTERM)` SIGTERM **tout le groupe de processus**.

Sites :
- `src/bin/calaos_server/McpServerManager.cpp:166` (chemin shutdown)
- `src/bin/calaos_server/JsonApiHandlerHttp.cpp:45` (destructeur)

(`ExternProc.cpp` sert de référence). Re-grep final de l'arbre : plus aucun `kill()` de
`ProcessHandle` sans garde pid (hors `PingInputSwitch.cpp` déjà correct).
