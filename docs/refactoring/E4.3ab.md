**comportement**, pas contre l'implémentation XML, pour qu'ils survivent à la migration.

## E4.3b — Round-trip XML save→reload
`tests/core/CalaosCoreFixture` sait sauver une config mais **n'assert jamais** que le rechargement
redonne la même chose. C'est le filet qui manquera le plus à E4.4d (migration pugixml, qui
reformate les fichiers) : écrit **maintenant**, il devient le juge de paix de la migration.
Couvrir : config → save → reload → **égalité sémantique** (jeu d'IOs, ids, params, pièces,
règles), y compris accents/entités XML et valeurs vides. Comparer sémantiquement, pas octet à
octet (le reformat est attendu et assumé en E4.4d).
