# T2.14 — Câblage des suites pytest dans `make check`

**Type** : infra (tests)
**Phase** : 2

## Contexte

Les suites Python (`tests/python/` : `test_auth.py`, `test_extern_proc.py`, `test_logger.py`,
`test_t116_mcp_client.py`, `test_t116_mcp_config_io.py`, `test_t116_roon.py` + `conftest.py`,
42+ tests issus de T1.8 et T1.16) ne sont **pas** câblées dans `make check` — délibéré en
wave 4 : `tests/Makefile.am` est gtest-only, le câblage pytest demande du travail configure.ac
(cf. FINDINGS « INFRA TESTS »). Aujourd'hui un test Python rouge ne casse rien : le filet CI
(T0.1) ne couvre que le C++.

`configure.ac:160` a déjà `AM_PATH_PYTHON([3], …)` et détecte pip/roonapi/reolink_aio/mcp —
la détection existe, seul le lancement des tests manque.

## Travail (fichiers : `tests/Makefile.am`, `configure.ac`)

1. Choisir le mécanisme automake : soit un script wrapper ajouté à `TESTS` +
   `dist_check_SCRIPTS` (pattern des `check-config-*.sh` existants, `tests/Makefile.am:17-18`),
   soit un hook `check-local`. Le wrapper lance `pytest` (ou `python -m unittest discover`)
   sur `tests/python/` avec le `$PYTHON` détecté par `AM_PATH_PYTHON`.
2. **Skip gracieux obligatoire** : si `$PYTHON` absent, si pytest/deps manquants (`mcp`,
   `roonapi`… selon les suites), exit code 77 (SKIP automake) — `make check` doit rester vert
   sur un système sans environnement Python complet. Réutiliser les `AC_CHECK`/conditionals
   déjà présents dans `configure.ac:160-191` (`HAVE_PYTHON_ROON`, etc.) plutôt que re-détecter.
3. `EXTRA_DIST`/`dist_check_SCRIPTS` pour que `make distcheck` embarque `tests/python/`.
4. Vérifier que `AM_TESTS_ENVIRONMENT` (`tests/Makefile.am:8`) expose ce qu'il faut
   (`PYTHONPATH` vers `src/lib/calaos-python` ou équivalent, comme le fait `conftest.py`).

## Acceptation

- `make check` exécute les suites Python et les compte dans le résumé (42+ tests).
- Un test Python volontairement cassé fait échouer `make check` (vérifié une fois puis retiré).
- Sur machine sans deps Python : SKIP propre, `make check` vert.
- `make distcheck` passe (fichiers Python distribués).
