## 1. Les deux constats

**(a) `IO/OLA/OLAOutputLightRGB.cpp:35` — `channel_red` déclaré sur `0..9999`.**
Les lignes voisines `:36` et `:37` déclarent `channel_green` et `channel_blue` sur **`0..512`**.
Le `9999` est **manifestement recopié de la ligne `universe` juste au-dessus** (`:34`). Un canal
DMX ne va pas au-delà de 512 : l'ioDoc — donc `calaos_installer` — **laisse saisir une valeur
qui ne peut pas marcher**, et seulement pour le rouge.

**(b) `IO/Mqtt/MqttOutputLightRGB.cpp:43` — la description de `path_y` dit « read the **x** value ».**
Copier-coller depuis `path_x` (`:42`). L'exemple lui-même est correct (`color/y`), seule la phrase
ment.

⚠️ **Ni l'un ni l'autre n'est un index de tableau** : ces deux chaînes n'entraient pas dans le
périmètre de T3.29 (qui ne touchait que les 8 chaînes portant `weather[0]`), et leurs exemples
sont **corrects**. C'est la même famille — *une chaîne d'ioDoc qui ment à l'utilisateur* — pas le
même défaut.

## 2. Le travail

1. `channel_red` : `9999` → `512`. **Un caractère de plus, trois de moins.**
2. `path_y` : « the x value » → « the y value ».
3. Les deux passent par `_()` ⇒ **`po/`** : reprendre les `msgid` à l'identique dans les
   catalogues suivis, comme T3.29 §5.4 (édition chirurgicale, **pas** `make -C po update-po`, qui
   churne ~2200 lignes par catalogue).
4. Mesurer le diff `--gendoc` avant/après : ce sont deux descriptions et une borne, **rien
   d'autre** ne doit bouger.

## 3. Les tests

**Commit de caractérisation d'abord.** Un cas par constat, sur le modèle du bloc (B) de
`tests/JsonPathSyntax_test.cpp` (lecture de `IODoc::genDocJson()`, aucun IO instancié) :

| Cas | Ce qu'il fige |
|---|---|
| `OlaRgbChannelsShareTheirBounds` | `channel_red`, `channel_green`, `channel_blue` ont **le même `max`** — formulé en **relation**, pas en constante, pour ne pas re-figer un `512` recopié |
| `MqttRgbPathDescriptionsNameTheirOwnAxis` | la description de `path_y` ne parle pas de `x` |

⚠️ `channel_red`/`green`/`blue` passent par `paramAddInt` : le `max` sort **en chaîne** dans le
JSON (`"512"`, pas `512`) — l'oracle de la maison est **type-strict**.

ligne `CXXLD` (voir [T3.36](T3.36.md)).
