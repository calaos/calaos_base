**Type** : suppression / dette
**Phase** : 2
**Décision utilisateur (2026-08-15, voir DECISIONS.md)** : MySensors n'est plus utilisé par
personne — c'est du code mort. Le retirer entièrement de la codebase.

## Contexte

Le support MySensors (gateway série/TCP + 16 types d'IO) n'a plus d'utilisateurs. T1.19 venait
de durcir `MySensorsController` (guards null-handle, alive-tokens) — ces fixes partent avec le
reste, c'est assumé. La suppression rend aussi **T3.2b obsolète** (« Thin IO subclasses —
MySensors ») : le fermer en même temps.

- `src/bin/calaos_server/IO/MySensors/` — 32 fichiers sources (.cpp/.h) : controller,
  controller list, protocole `MySensors.{cpp,h}`, et les classes d'IO
  (InputAnalog/InputString/InputSwitch/InputSwitchLongPress/InputSwitchTriple/InputTemp/
  OutputAnalog/OutputDimmer/OutputLight/OutputLightRGB/OutputShutter/OutputShutterSmart/

  transport, série + TCP) : les retirer, garder les tests WebCtrl/Gpio.

  seules ses sources MySensors partent s'il y en a).

  eux-mêmes → aucun registre central à éditer. La doc générée (`genDocIO`) perd les entrées
  automatiquement.
