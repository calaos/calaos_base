## Findings

### Major — security: `createRandomUuid` weak reseed feeds auth tokens
`Utils::createRandomUuid` (`Utils.cpp:845`) does `srand(t1.tv_usec * t1.tv_sec)` then `rand()` — non-cryptographic, clock-only seed, **reseeded on every call** (clobbering global `rand()` state). It feeds `McpServerManager`'s 256-bit token (`= strip(createRandomUuid()) + strip(createRandomUuid())`, T1.7). **Fix:** seed a PRNG once (or draw from `std::random_device` / `/dev/urandom` / OpenSSL `RAND_bytes`); never reseed `rand()` per call.

### Major — correctness: `tcpsocket::Recv()` appends a non-NUL-terminated buffer as a C-string
`tcpsocket.cpp:345` — a 4096-byte read buffer is appended as `string(buffer)` (or via `+=`) without using the returned length, so a full read with no embedded NUL reads past the data (and a payload with an embedded NUL truncates). **Fix:** append exactly `recv_len` bytes (`data.append(buffer, recv_len)`).

### Minor — security: `getTmpFilename` builds a predictable `/tmp` name via `rand()`
`Utils.cpp:990` — `int cpt = rand(); do { tempfname = "/tmp/calaos"+prefix+"_"+to_string(cpt)+"."+ext; cpt++; } while (FileUtils::exists(tempfname));`. Predictable name + exists()-then-open leaves a TOCTOU/symlink window. **Fix:** use `mkstemp()` (atomic `O_EXCL`).

### Minor — edge-case: other `Utils` filesystem helpers
- `getFileContent` (around `Utils.cpp:~940`) indexes `&buff[0]` on a possibly empty buffer (filesize 0 / negative) — validate `filesize > 0` before indexing.
- `getuid`/`getpwuid` result used without a null check when resolving the home path — guard.

## Acceptance
- Random tokens/UUIDs no longer come from a per-call-reseeded `rand()`.
- `tcpsocket` appends exactly the received length; binary payloads round-trip.
- Temp files created atomically; no empty-buffer OOB in `getFileContent`.

## Verification
`make check`; unit test: many UUIDs, all distinct and not clock-correlated; a `tcpsocket` receive test with an embedded NUL and with a full 4096-byte read; a temp-file test that survives a pre-planted symlink.
