## Goal
Fix the build/packaging defects that surface the moment T0.1 wires `make check` into CI, and remove the obsolete Travis harness.

## Findings
- **major/test** `src/lib/libquickmail/Makefile.am:54` — `TESTS = test_quickmail test_quickmaillight` is ungated and the demo programs attempt a **live SMTP send** to a hardcoded bogus host (`test_quickmail.c:77` → `quickmail_send(..., "smtp.mydomain.com", 25, ...)`). Under CI `make check` this hangs/fails. **Fix:** remove these third-party demos from `TESTS` (or guard behind a disabled conditional).
- **major/build** `Dockerfile:38` — the version-injection `sed` never matches (BRE `\s+` means literal `+`, absent from the file), so every published image ships `PKG_VERSION_STR "git"`. **Fix:** use ERE, e.g. `sed -E -i 's/^#define[[:space:]]+PKG_VERSION_STR[[:space:]]+"[^"]+"/#define PKG_VERSION_STR "'"$APP_VERSION"'"/'`.
- **major/build** `Dockerfile:36` — the builder stage `git clone`s `master` from GitHub, discarding the `context: .` both CI workflows pass; the image is built from remote HEAD, not the triggering commit. **Fix:** `COPY . /calaos_base` and build from the context.
- **minor/build** `src/bin/calaos_server/Makefile.am:24,38,8-9` — the same dead includes (`IO/Scripts`, `src/lib/cJSON`) and the duplicate `-DPACKAGE_DATA_DIR` (→ `-Wmacro-redefined` every build) that T0.2 fixes in `tests/`. Apply the same cleanup to the production Makefile.
- **minor/other** `scripts/linux/script.sh:7` — references a non-existent `/scripts/build.sh`; `scripts/lib.sh` and `scripts/osx/*` use `$TRAVIS_BUILD_DIR`, brew, googletest 1.8.0 — all dead now that CI is GitHub Actions. **Fix:** delete the dead Travis harness.

## Acceptance
- `make check` no longer attempts an outbound SMTP connection.
- Published images carry the real version string and reflect the built context.
- No dead `-I` / duplicate define in the production Makefile; no `-Wmacro-redefined`.
- Obsolete Travis scripts removed.

## Verification
`make check` runs offline; `docker build` from a local checkout produces an image whose `--version` matches; `grep -rn TRAVIS scripts/` empty.
