# T3.163 — `WAGO_GET_VERSION` annonce un modèle qui n'est pas celui du module

**Statut** : 📋 · **Type** : fix · **Phase** : 3
**Origine** : mesuré en livrant l'arbitrage de [T3.156](T3.156.md), 2026-09-07, en vérifiant que
les modèles d'une même version ne divergent pas.

---

## 1. Ce qui est mesuré

La réponse est `WAGO_GET_VERSION <H>.<L> <modèle>`. Le troisième champ est une **constante écrite
en dur** dans chaque programme, et elle n'a pas suivi les copies :

| Version | modèle annoncé par chaque `.pro` | fidèle au nom du fichier ? |
|---|---|---|
| **3.0** | `841`→`750-849` · `849`→`750-849` · `880`→`750-849` · `881`→`750-849` · `889`→`750-849` · `891`→`750-849` · `893`→`750-849` | ⛔ **1 sur 7** |
| 2.3 | `841`→`750-841` · `849`→`750-849` · `880`→`750-841` · `881`→`750-841` · `889`→`750-849` · `891`→`750-841` · `893`→`750-841` | 2 sur 7 |
| 2.2 | `841`→`750-841` · `849`→`750-849` · `881`→`750-841` | 2 sur 3 |

⇒ **en 3.0, les sept modules se présentent tous comme un 750-849.** Le champ ne permet pas
d'identifier le module ; c'est une constante recopiée avec le fichier, jamais mise à jour.

## 2. Qui le lit

`src/bin/tools/wago_test.cpp:339` l'affiche tel quel sous le libellé **`WAGO type:`** — un opérateur
qui diagnostique une installation lit donc un modèle faux. Aucun autre consommateur dans
`calaos_base` : `calaos_server` ne demandait pas la version avant `T3.156`, et le correctif de
`T3.156` **n'utilise que le champ de version**, jamais le modèle — c'est écrit à la source
(`WagoMap::plcVersionReply_cb`).

## 3. Ce qui est demandé

Corriger la constante dans les programmes de `calaos_wago` — ⛔ **aucune ligne de `calaos_base`** —
et, du côté de l'outil, ne pas présenter comme un fait un champ que rien ne tient : soit le libeller
« modèle annoncé », soit le retirer.

⛔ **Ce qu'il ne faut pas faire** : dériver quoi que ce soit de ce champ dans `calaos_server`. La
version, elle, est **cohérente sur les 29 programmes qui portent la commande** (30 `.pro` relevés un à un, `Wago_1.8/wago_849_test.pro` n'ayant pas de gestionnaire `WAGO_GET_VERSION`) ; le
modèle ne l'est pas.

## 4. ⛔ Le nu

Relevé par `strings -n 4` sur les `.pro` CoDeSys, jamais par une trame reçue d'un automate. Que la
réponse réelle porte bien cette constante est **déduit** de la lecture du `CONCAT`.
