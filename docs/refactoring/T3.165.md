# T3.165 — les deux autres envois UDP qui prêtent une mémoire locale à uvw

**Statut** : 📋 · **Type** : fix + test · **Phase** : 3
**Origine** : recensement fait par [T3.142](T3.142.md), 2026-09-13. `F-UDP-7`.

---

## 1. Ce qui est lu

`T3.142` a fermé la divulgation de `UDPServer`. Le **motif** — une mémoire à durée de vie locale
confiée à `uvw::UDPHandle::send(…, char *, …)`, dont le suppresseur ne fait rien — subsiste à
**deux** endroits de l'arbre. Recensement exhaustif, `src/bin` et `src/lib` :

```
src/bin/calaos_server/IO/Wago/WagoMap.cpp:570
src/bin/calaos_server/IO/LAN/WOLOutputBool.cpp:130
```

(`WODaliRVB` et les autres IO Wago n'envoient rien eux-mêmes : ils passent par
`WagoMap::SendUDPCommand()`, donc par le premier site.)

### `WagoMap::UDPCommand_cb` — la commande est détruite juste après avoir été postée

```cpp
WagoMapCmd &cmd = udp_commands.front();
...
handleSrv->send(host, WAGO_LISTEN_PORT, (char *)cmd.udp_command.c_str(),
                cmd.udp_command.length() + 1);
if (cmd.no_callback)
    udp_commands.pop();          // <- la string qu'on vient de prêter meurt ici
```

⭐ **`SendUDPCommand()` pose `no_callback = true` sans condition** (`:418`) : **toutes** les
commandes sorties par là — `WAGO_SET_SERVER_IP`, `WAGO_HEARTBEAT`, `WAGO_GET_VERSION`, les écritures
DALI — sont dépilées, donc libérées, **immédiatement après** le `send`.

### `WOLOutputBool::doWakeOnLan` — le paquet magique meurt au retour

```cpp
vector<uint8_t> magicPacket;          // local
...
udp_con->send("255.255.255.255", 7, (char *)magicPacket.data(), magicPacket.size());
```

Le handle est **neuf** à chaque réveil, donc sa file d'envoi est vide et `uv__udp_sendmsg` part en
ligne : le tampon est lu avant de mourir. ⚠️ **Sûr par accident, pas par construction.**

## 2. ⛔ Ce qui n'est PAS mesuré

**Aucune divulgation n'a été produite sur ces deux sites.** Ils sont recensés comme étant de la même
**forme** que celle de `T3.142`, pas comme étant défaillants. Ce qui les protège aujourd'hui est
fragile et non écrit :

- côté Wago, la sérialisation par minuteur de 50 ms de `UDPCommand_cb` — un envoi par tour, donc
  une file d'envoi vide à chaque fois. Rien ne le garantit : le `handleSrv` de `WagoMap` sert aussi
  les lectures DALI, et `T3.164` va ajouter du trafic sur ce chemin ;
- côté WOL, la fraîcheur du handle — qui disparaîtrait dès qu'on le réutiliserait, ce qui est
  précisément ce qu'un correctif de fuite de descripteurs ferait.

⭐ **Le premier travail du ticket est de mesurer, pas de corriger** : produire ou ne pas produire la
mise en file sur chacun des deux sites, et le dire. Un correctif posé sans ça serait une garde dont
personne ne saurait ce qu'elle garde.

## 3. Ce qu'il faut faire

1. **Mesurer** : sur chaque site, poster deux envois dans le même tour de boucle et lire ce que le
   correspondant reçoit — ⛔ jamais « ça ne plante pas », le défaut est **silencieux**. La charge
   Wago et le paquet magique doivent être comparés **entiers**, pas par leur longueur (le motif de
   `T3.142` : 19 octets divulgués pour 19 octets attendus).
2. **Corriger**, si et seulement si la mesure le demande : `Calaos::sendDatagram()` porte depuis
   `T3.142` une surcharge qui prend la charge par `const std::string &`, la copie et la **donne** à
   uvw ; elle est faite pour ça. ⚠️ Le site Wago envoie `length() + 1` — le **NUL final fait partie
   du protocole automate**, la surcharge devra le recevoir explicitement et non l'inventer.
3. ⚠️ **Ne pas compter sur le filet de `T3.142` pour ces deux sites.** Sa barrière `exit 77` sonde
   justement la surcharge prêteuse : un défaut réel y produirait un `SKIP`, pas un rouge
   ([T3.166](T3.166.md) / `F-UDP-10`). Les cas de ce ticket doivent donc être **les leurs**.
4. **Une sonde statique** qui refuse le prochain appelant de la surcharge prêteuse dont l'argument
   n'est pas manifestement plus long que la requête, dans l'esprit de `tests/check-*.sh`. ⚠️ À
   arbitrer : la surcharge prêteuse a un usage légitime (un tampon membre, un buffer de pool), donc
   une sonde qui l'interdirait tout court serait désarmée le jour où elle mordrait.

## 4. ⛔ Le Nu

- Les deux sites sont **lus**, jamais joués. Le compte de 2 est celui de `src/bin` et `src/lib` ;
  `src/lib/uvw` (la bibliothèque) n'est pas du ressort de ce ticket.
- La sérialisation à 50 ms de `WagoMap` est **lue dans le code**, pas mesurée sous charge.
