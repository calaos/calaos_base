# T3.223 — `smtpsocket.c` écrit sans `MSG_NOSIGNAL`, et seul le `SIG_IGN` du serveur le couvre

**Statut** : 📋 · **Type** : fix (robustesse) · **Phase** : 3
**Origine** : recensement des sites d'envoi fait par [`T3.167`](T3.167.md).
**Dépend de** : —

---

## 1. Ce qui a été relevé

`src/lib/libquickmail/smtpsocket.c:94` :

```c
while (len > 0 && (l = send(sock, buf, len, 0)) < len) {
```

C'est le **dernier** appel brut de la famille `send` de l'arbre sans `MSG_NOSIGNAL` : les cinq de
`src/lib/tcpsocket.cpp` (`:204`, `:238`, `:252`, `:317`, `:319`) et celui de
`src/bin/calaos_server/IO/Wago/libmbus/mbus_sock.c:293` l'arment tous, et
`ExternProc.cpp` vient de l'armer.

## 2. ⚠️ Pourquoi ce n'est PAS chaud

Ce code ne tourne que dans `calaos_server`, qui fait `signal(SIGPIPE, SIG_IGN)`
(`src/bin/calaos_server/main.cpp:69`). Un serveur SMTP qui raccroche pendant l'envoi donne donc
`EPIPE` et non la mort du processus. ⛔ **Ce qui le rend fragile n'est pas le défaut mais sa
dépendance** : la protection vit dans un autre fichier, tenue par rien, et la ligne elle-même est
du code **vendu** que personne ne relit. `T3.167` a mesuré exactement la forme voisine de cette
fragilité : la disposition d'un processus ne voyage pas — `uv_spawn` remet tout à `SIG_DFL` dans
l'enfant — et un sidecar qui réutiliserait cette bibliothèque serait nu.

## 3. Ce qu'il faut faire

Armer le drapeau au site d'envoi, comme les six autres. ⚠️ **Le cas est le point dur** : cette
bibliothèque n'est exercée par aucune suite, et un cas qui vérifierait la seule **présence** du
drapeau dans le source serait un capteur à nom connu d'avance. Ce qui se mesure est le
comportement : un pair qui cesse de lire — `shutdown(SHUT_RD)`, jamais `close()`, voir le §5.1 de
[`T3.167`](T3.167.md) pour pourquoi — et un envoi qui rend `EPIPE` au lieu de tuer, dans un
processus qui **n'ignore pas** `SIGPIPE`.

## 4. ⛔ Nu

- ⛔ **Rien n'a été joué** : le relevé est une lecture du source, pas une exécution. Que ce chemin
  soit atteignable depuis une configuration réelle (un IO d'envoi de courriel) n'a pas été vérifié.
