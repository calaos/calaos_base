## Findings

### Major — security: bundled TinyXML 2.5.3 (2007) parses network-pushable config
`src/lib/TinyXML/tinyxml.h:94-96` — `TIXML_MAJOR_VERSION = 2; MINOR = 5; PATCH = 3`. This unmaintained 2007 release of classic TinyXML (≤ 2.6.2) is affected by **CVE-2023-34194** (reachable assertion / DoS on crafted XML) and is used to parse `io.xml`/`rules.xml`, which can be network-pushed (RemoteUI provisioning / config upload). **Fix:** migrate to maintained TinyXML2 (or a patched/current parser) and drop the vendored 2.5.3 tree.

## Remediation
- Introduce TinyXML2 as the XML parser (vendored or system dep).
- Migrate consumers one at a time (start with `CalaosConfig`), keeping XML round-trip fidelity.
- Remove `src/lib/TinyXML/` and its `Makefile.am` references at the end.

## Acceptance (epic)
- No bundled TinyXML 2.5.3 in the tree.
- Config parsing on TinyXML2 (or an equivalent maintained parser).
- The crafted-XML DoS (CVE-2023-34194) is no longer reachable.
- Config round-trip tests (E4.3) green.

## Verification
Load real `io.xml`/`rules.xml` (round-trip identical) + fuzzed/crafted XML without crash/assert; `grep -rn TIXML src/` shows no 2.5.3 tree.
