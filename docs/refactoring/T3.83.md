# T3.83 — `UrlDownloader` publie **tout corps de réponse HTTP** dans le journal

**Statut** : 📋 · **Type** : fix (sécurité, hygiène de journal) · **Phase** : 3 · **Dépend de** : —
**Origine** : trouvé en balayant l'arbre pour [`T3.81`](T3.81.md) §4, à la question « le jeton
Hifi Rose fuit-il ailleurs qu'à `AVRRose.cpp` ? ». **Fiché, PAS corrigé** : le périmètre est bien
plus large que celui de T3.81, qui portait sur `ExternProc` et sur un site d'`Audio/`.

---

## 1. Le défaut

`src/lib/UrlDownloader.cpp:692` :

```cpp
cDebugDom("urlutils") << "Response data: " << m_downloadedData;
```

`m_downloadedData` est **le corps de réponse HTTP entier**, quel que soit le driver qui a lancé le
transfert. Même famille exacte que le défaut fermé par [`T3.81`](T3.81.md) : un transport
générique qui journalise ce qu'il ne comprend pas.

⭐ **Ce qui rend le site sûr de lui, c'est qu'il croit déjà se protéger** : le même fichier caviarde
les identifiants d'**URL** partout ailleurs (`Utils::maskUrlCredentials`, `:446,477,733`), et rien
n'a jamais été fait pour le **corps**. La protection d'un canal a servi de preuve pour l'autre.

## 2. Ce qui y passe, mesuré sur un cas

- ⭐ **Le jeton d'appareil Hifi Rose.** `AVRRose::registerDevice()` lit
  `jdoc["data"]["deviceRoseToken"]` dans la réponse à `POST /device_connected` ; **ce corps
  passe par cette ligne**. [`T3.81`](T3.81.md) a fermé le site qui journalisait la valeur extraite —
  celui-ci journalise le document dont elle vient. **Un jeton ne fuit pas par un seul point.**
- ⚠️ **Le reste n'a PAS été recensé.** Tout driver HTTP de l'arbre traverse `UrlDownloader` :
  caméras IP, Hue, services de notification, Squeezebox. Ce ticket commence par ce recensement, il
  ne le suppose pas.

Niveau DEBUG, donc pas imprimé par défaut — la même objection que [`T3.79`](T3.79.md) §3.1 a
tranchée par la mesure : DEBUG est ce qu'un exploitant allume avant de coller son journal dans un
rapport de bogue public.

## 3. Ce qu'il faudrait épingler

- La doctrine de [`T3.79`](T3.79.md), reprise par [`T3.81`](T3.81.md) : **journaliser ce qu'on
  publie, pas ce qu'on devine devoir cacher** — ici la taille du corps et le code de statut, que la
  ligne voisine publie déjà (`"Finished with status code: "`).
- ⚠️ **Anti-vacuité obligatoire** : le cas doit asserter que le domaine `urlutils` n'est pas muet à
  DEBUG avant de conclure qu'aucun secret n'y est.
- ⛔ **Le harnais existe** : `tests/UrlDownloader_test.cpp` monte déjà un serveur HTTP local qui
  répond un corps choisi. Un cas y fait tenir un secret dans ce corps et relit `std::cout`.
- ⚠️ **Le coût en diagnostic est réel ici, contrairement à T3.81** : le corps d'une réponse est ce
  qu'on lit pour comprendre pourquoi un driver ne décode pas. À arbitrer — publier la taille seule,
  ou laisser le contenu derrière un domaine que personne n'allume par accident.
