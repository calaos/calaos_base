# E4.4a — Introduire pugixml (build only, zéro consommateur)

**Type** : infra · **Phase** : 4 · **Série** : E4.4 (1/5)
**Décision utilisateur (2026-08-15)** : migrer TinyXML 2.5.3 + TinyXPath → **pugixml**
(XPath 1.0 natif, maintenu, MIT). Voir PHASE4.md.

## Objectif
Rendre pugixml disponible et linké, **sans modifier un seul consommateur**. À la fin de ce
ticket, TinyXML fonctionne toujours et pugixml compile à côté.

## Travail
1. **Paquet distro — VÉRIFIÉ** : `debian:12` fournit `libpugixml-dev` **1.13-0.2** avec
   `pugixml.pc`, et `/usr/include/pugiconfig.hpp:24` laisse `PUGIXML_NO_XPATH` commenté →
   **XPath actif dans le build Debian**. Utiliser `PKG_CHECK_MODULES`. Vérifier la dispo Arch
   (paquet `pugixml`) ; si un environnement de build ne l'a pas, prévoir un fallback vendored
   (`pugixml.hpp`/`pugixml.cpp`, MIT) — mais **le paquet est la voie par défaut**.
2. `configure.ac` + `src/lib/Makefile.am` : détection/compilation, flags exportés comme pour
   les autres libs communes. Le résumé de configure doit mentionner pugixml.
2bis. **IMAGES (obligatoire si voie paquet)** — sinon tous les environnements de build cassent :
   - `./Dockerfile` stage **dev** (deps de build, ~l.20-27) → paquet **-dev** ;
   - `./Dockerfile` stage **runtime** (~l.63-65) → paquet **runtime** (nom exact à vérifier) ;
   - `.devcontainer/Dockerfile` → paquet -dev ;
   - `.github/workflows/ci.yml` → seulement s'il installe des deps hors image.
   ⚠️ L'image préconstruite `vsc-calaos_base-…` est antérieure : **elle devra être reconstruite**
   pour que le changement prenne effet en usage normal (installer le paquet à la volée dans le
   conteneur suffit pour la validation du ticket).
3. Test de fumée minimal (`tests/`) : parser un petit XML, lire un attribut, exécuter une
   requête XPath simple — prouve que la lib est bien linkée **et que XPath est actif**.

## Interdits
Toucher un consommateur TinyXML, supprimer quoi que ce soit de `src/lib/TinyXML/`.

## Acceptation
`./autogen.sh && ./configure && make && make check` verts ; nouveau test de fumée au vert ;
`grep -c TIXML src/` inchangé.
