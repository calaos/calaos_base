> These are the subprocess entry points spawned over `ExternProc`. Disjoint from the framework itself (`IO/ExternProc.*`, T1.9) and from the thin IO subclasses (T3.2b/c/e).

## Findings

### Major — correctness: Wago reconnect retry drops the register address offset
`WagoExternProc_main.cpp:94` — the first read uses `read_bits(address + offset, …)` (`:90`) but the post-reconnect retry reads `read_bits(address, …)` (`:94`); same pattern for `read_words` (`:194` vs `:198`). For `read_output_*` (offset `0x200`) the retry reads the **wrong registers**. **Fix:** use `address + offset` in the retry calls too.

### Major — edge-case: argv off-by-one dereferences the NULL terminator
`WagoExternProc_main.cpp:302` — `if (argc >= 1) wago_host = argv[1];` and similar: `argv` is indexed one past what `argc` guarantees, so with optional args omitted it dereferences the `NULL` terminator (or reads past `argv`). **Fix:** correct the bounds (`argc > N` before `argv[N]`).

### Major — error-handling: subprocess auto-restart has no backoff or cap
`WagoMap.cpp:63` — the subprocess auto-restart loop re-spawns immediately with no backoff and no retry cap, so a driver that fails at startup spins in a tight respawn loop. **Fix:** add exponential backoff and a bounded retry count with an error log.

### Minor — edge-case: OWFS scan hex guard drops boundary characters
`IO/OneWire/*_main.cpp:184` — `if ((s[0] > '0' && s[0] < '9') || (s[0] > 'A' && s[0] < 'F'))` uses strict `>`/`<`, dropping devices whose address starts with `'0'`, `'9'`, `'A'`, or `'F'`. **Fix:** inclusive comparisons (`>= '0' && <= '9'`, `>= 'A' && <= 'F'`), ideally `isxdigit` after an empty-string check.

### Minor — edge-case: MQTT binary payload treated as a C-string
`MqttExternProc_main.cpp:239` — `json_object_set_new(root, "payload", json_string((const char*)m->payload));` ignores `m->payloadlen`; a non-UTF8/binary payload makes `json_string` return NULL (field dropped) and embedded NULs truncate. `messageReceived` (`:143`) also omits a `json_is_object()` check. **Fix:** use `json_stringn(m->payload, m->payloadlen)` (or base64) and validate `json_is_object` before decoding.

## Acceptance
- Wago output-register reads after a reconnect target the correct addresses.
- Missing optional CLI args do not dereference past `argv`.
- A failing subprocess backs off (not a tight respawn loop).
- OWFS scan keeps boundary-hex devices; MQTT binary payloads not silently dropped/truncated.

## Verification
`make` with `--with-mqtt --with-owfs`; a Wago reconnect test confirming correct register addresses; launch a driver with missing args (no crash); simulate repeated subprocess failure and observe backoff.
