# T3.8 — AVRRose / AVRRoseNotifServer : lifetimes async

**Type** : fix · **Phase** : 3
**Origine** : finding revue T3.1 (fichiers non couverts par son périmètre effectif).

## Problème
`AVRRose.cpp` : pollTimer/postRequest capturent `[this]` brut ; retry
`Timer::singleShot(10.0,[this])` non gardé. `AVRRoseNotifServer.cpp` : captures uvw `[this]`
non gardées. UAF possible à la destruction avec requêtes/timers en vol.

## Travail
Étendre le pattern aliveTag de T3.1 (`AVReceiver::aliveTag`, weak_ptr capturé par valeur,
reset en tête de dtor) à tous les chemins async de ces deux fichiers. Iso-comportement.

## Acceptation
Build + `make check` verts ; grep : plus aucune capture async `[this]` non gardée dans les
deux fichiers.
