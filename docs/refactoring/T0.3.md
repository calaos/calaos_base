## Fichiers possédés
- `tests/core/` (nouveau)
- `tests/Makefile.am`

## Objectif
Poser l'infrastructure de tests du cœur métier, réutilisée par les tickets de correction (T1.x) et de refactoring (T2.x). Aujourd'hui **zéro test** couvre `IOBase`, `ListeRoom`, `ListeRule`, `Rule`, `Condition*`, `Action*`, `CalaosConfig`.

## À faire
- Créer `tests/core/` avec des fixtures GTest chargeant un `io.xml`/`rules.xml` **minimal en mémoire** (chaîne, pas de fichier disque si possible).
- Helpers réutilisables : round-trip XML (load → save → reload et comparaison), création/suppression d'un IO, instanciation d'une règle simple.
- Un test « smoke » : charger un config minimal, vérifier qu'un IO est instancié et retrouvable par id.
- Enregistrer le répertoire dans `tests/Makefile.am`.

## Acceptance
- `make check` exécute le test smoke cœur.
- Les helpers sont documentés (docstring d'en-tête) pour être repris par T1.1/T1.2/T1.3/T2.4.

## Vérification
`make check` vert avec le nouveau test ; les tickets T1.x peuvent `#include` les fixtures sans duplication.

> ⚠️ Sérialiser avec T0.2/T0.5 (partage `tests/Makefile.am`).
