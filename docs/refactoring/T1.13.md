# T1.13 — LAN & Hue memory safety

| Phase | Type | Depends on | Status |
|---|---|---|---|
| 1 | fix | Phase 0 | 📋 Backlog |

## Owned files
- `src/bin/calaos_server/IO/LAN/` (`PingInputSwitch.{cpp,h}`, `WOLOutputBool.{cpp,h}`)
- `src/bin/calaos_server/IO/Hue/` (`HueOutputLightRGB.{cpp,h}`)

## Findings

### Critical — security: off-by-one heap overflow + uninitialized `argv[0]` in ping
`PingInputSwitch.cpp:98-105`:
```cpp
const char **argarray = new const char*[tok.size() + 1];
unsigned index = 1;                       // starts at 1
for (auto it = tok.begin(); it != tok.end(); it++) { argarray[index] = it->c_str(); index++; }
argarray[index] = NULL;                   // index == tok.size()+1 → OOB write
ping_exe->spawn(tok[0].c_str(), (char **)argarray);
```
`index` starts at **1**, so `argarray[0]` is never assigned (uninitialized pointer handed to `spawn` as argv[0]) and the terminating `NULL` is written at `argarray[tok.size()+1]`, **one past** the `tok.size()+1`-element array → heap buffer overflow. **Fix:** start `index = 0`, fill `argarray[0..tok.size()-1]`, terminate at `argarray[tok.size()]`.

### Critical — lifetime: Hue polling timer captures `this`, destructor does nothing
`HueOutputLightRGB` sets up a repeating polling `Timer` in its constructor whose lambda captures raw `this`, but `~HueOutputLightRGB()` is **empty** (`HueOutputLightRGB.cpp:106`) — it never stops/deletes the timer. On IO deletion (config reload) the timer keeps firing into a freed object (**UAF**) and leaks. **Fix:** own the timer (`unique_ptr`/member) and stop+destroy it in the destructor; guard the poll callback against destruction.

### Major — edge-case: Wake-on-LAN rejects uppercase MAC addresses
`WOLOutputBool.cpp:74` — `parseHex` only maps `'a'-'f'` (no `'A'-'F'`), and the validation loop (`:87-91`) likewise accepts only `'0'-'9'`/`'a'-'f'`. A normal uppercase MAC like `AA:BB:CC:DD:EE:FF` fails with "Wrong MAC address" and no packet is sent. **Fix:** accept `'A'-'F'` in both `parseHex` and the validation loop (or lowercase the address first).

## Acceptance
- Ping IO built and executed under ASan → no heap overflow, `argv[0]` well-defined.
- Deleting a Hue RGB IO (config reload) → timer stopped, no UAF/leak (ASan).
- WOL with an uppercase MAC → packet sent.

## Verification
`make check` under ASan for the ping-argument build and the Hue-IO create/delete cycle; a WOL unit test with mixed-case MAC input.
