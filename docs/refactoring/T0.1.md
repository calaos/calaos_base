| Phase | Type | Depends on | Status |

## Owned files
- `.github/workflows/ci.yml` (new)

## Goal
Add a GitHub Actions job that builds the project and runs `make check` on every PR and push. Today the CI holds only Docker build/publish workflows (`docker-publish.yml`, `docker-publish-dev.yml`) — **none runs the tests**. The 3 existing GTest tests therefore never guard a merge.

## To do
- Install the build dependencies (`libuv`, `jansson`, `libcurl`, `luajit`, `sigc++`, `sqlite3`, `openssl`, `gtest`) on the CI image (Debian 12, to match the `Dockerfile`).
- Run `./autogen.sh && ./configure && make && make check`.
- Fail CI if any test fails.

## Acceptance
- A PR triggers the build + the existing tests (`ColorValue_test`, `ExpressionEvaluator_test`, `FileUtils_test`).
- A red test ⇒ red CI.

## Verification
`gh pr checks` shows the "build & test" job; break a test on purpose and confirm the CI turns red.

> Note: several Phase-0 findings (libquickmail demo SMTP in `TESTS`, gtest LDADD ordering) will surface the moment `make check` runs in CI — they are fixed by T0.6 and T0.2 respectively, which should land alongside this ticket.
