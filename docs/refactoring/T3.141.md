# T3.141 — `resource<>()` peut rendre `nullptr`, et aucun des 45 sites de l'arbre ne le regarde

**Statut** : 📋 · **Type** : fix · **Phase** : 3
**Origine** : revue de merge de [T3.109](T3.109.md), §2 point E — la question que la fiche
laissait explicitement ouverte.

---

## 1. Le fait, lu à la source

`uvw::Loop::resource<R>()` rend **`nullptr`** quand l'initialisation de la ressource échoue :

```cpp
// src/lib/uvw/src/uvw/loop.hpp:250-254
auto ptr = R::create(shared_from_this(), std::forward<Args>(args)...);
ptr = ptr->init() ? ptr : nullptr;
return ptr;
```

L'arbre appelle `resource<>()` à **45 endroits** hors `uvw/`. **Aucun** ne teste le retour : tous
déréférencent le pointeur dans les lignes qui suivent.

## 2. Ce qui est réellement atteignable, et ce qui ne l'est pas

`init()` de `TcpHandle`, `PipeHandle`, `UDPHandle`, `TimerHandle`, `AsyncHandle`, `IdleHandle`,
`SignalHandle` appelle un `uv_*_init` qui **n'ouvre aucun descripteur** sur Linux et ne peut donc
pas échouer pour épuisement. Ces 44 sites-là sont sûrs **par accident**, pas par contrat.

⛔ **Le 45ᵉ ne l'est pas.** `PollHandle::init()` appelle `uv_poll_init_socket`, qui échoue
(`EINVAL`, `EBADF`, descripteur déjà surveillé) :

```cpp
// src/lib/UrlDownloader.cpp:333 puis :337
ctx->poll = uvw::Loop::getDefault()->resource<uvw::PollHandle>(uvw::OSSocketHandle{s});
...
ctx->poll->on<uvw::PollEvent>([self, fd](const uvw::PollEvent &ev, auto &) {
```

Quatre lignes séparent la création du déréférencement, et rien entre les deux ne regarde le
pointeur : un `uv_poll_init_socket` refusé est un **SIGSEGV dans le serveur**, sur le chemin de
tout téléchargement HTTP (caméras, notifications sortantes, MCP).

## 3. Ce que le ticket demande

1. La garde sur `UrlDownloader.cpp:333` : rendre la main proprement à libcurl (l'appelant est le
   `socket callback` de `curl_multi_socket_action`) et **nommer** le refus, plutôt que déréférencer.
2. Un recensement statique, à la manière de `tests/check-test-deps.sh`, qui refuse un
   `resource<...>()` dont le retour est déréférencé sans avoir été regardé — sinon le 46ᵉ site
   arrivera avec le même trou.
3. ⚠️ **Ne pas** ajouter 44 gardes mortes : les autres sites sont sûrs et le dire coûte moins cher
   que le prouver à chaque relecture. La sonde de 2. est ce qui tient la phrase.

## 4. Ce que la revue n'a pas fait

Le SIGSEGV n'a **pas** été provoqué en service : il est établi par lecture (`loop.hpp`, `poll.hpp`,
`uv_poll_init_socket`), pas par une exécution. Un cas qui le reproduit — un descripteur fermé remis
à libcurl — reste à écrire.
