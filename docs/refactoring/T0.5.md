## Goal
Provide automatic formatting consistent with the project conventions **without reformatting existing code** (a mass reformat would conflict with every in-flight ticket).

## Conventions to encode (see `AGENTS.md:161`)
- C++: camelCase variables/functions/methods, PascalCase classes.
- Opening brace `{` on a new line (Allman).
- Single-line bodies without braces; multi-line bodies always braced.
- Constructor init lists: `:` at the end of the declaration line, one initializer per line with trailing `,`.

## To do
- Create `.clang-format` reproducing these rules (Allman brace base).
- `.editorconfig` (indentation, line endings, charset).
- Extend `ci.yml` with a `clang-format --dry-run --Werror` check **on the PR diff only** (`git diff --name-only origin/master` filtered to `.cpp/.h`), not the whole tree.

## Acceptance
- The CI check fails if **newly modified** code is not formatted.
- No diff imposed on files untouched by the PR.

## Verification
A PR with badly formatted code fails the check; a clean PR passes. No mass-reformat commit.
