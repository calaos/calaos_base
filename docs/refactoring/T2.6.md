## Findings

### Major — correctness: `ThreadedQueue::tryPop()` moves the front but never pops it
`ThreadedQueue.h:48` — `item = std::move(queue.front()); return true;` with **no** `queue.pop()` (compare `waitPop`, which pops). Any caller of `tryPop` keeps getting the same (moved-from) element forever; the queue never drains. **Fix:** add `queue.pop();` after moving the front element.

### Major — edge-case: malformed color string crashes via `std::out_of_range`
`ColorUtils.cpp:133` — after stripping the prefix, `s.erase(s.find_last_of(')'));` is called on input with no `)` (e.g. `"rgb(1,2,3"`), so `find_last_of` returns `npos` and `erase(npos)`… then downstream indexing throws `std::out_of_range`. **Fix:** validate the presence of `)` (and overall shape) before `erase`/indexing; reject malformed input gracefully.

### Minor — correctness: Calendar month/day arithmetic bugs
- `Calendar.cpp:273` (`monthDown`) — decrementing January (1) yields 0, then sets `month = 11` (November), **skipping December**. **Fix:** set `month = 12`.
- `Calendar.cpp:318` (`dayDown`) — after the decrement it calls `setYear(year)` instead of `setDay(day)`, so the day is never committed. **Fix:** `setDay(day)`.
- `Calendar.cpp:131` (`getDayFromDate`) — guard `if (dayId < 0 || dayId > 7)` allows `dayId == 7` to read `days[7]` (array has 7 elements, indices 0-6) → OOB. **Fix:** guard `dayId > 6`.
- `Calendar.cpp:62` (`loadCurrentTimeZone`) — `while (std::getline(f, l) && l == "\n")` never matches (getline strips the newline), so the intended blank-line skip is dead. **Fix:** compare against the empty string.

### Minor — edge-case: `isspace` on a possibly-negative `char` (Params)
`Params.cpp:81` (and `:89`) passes `str[i]` (a possibly-negative `char`) directly to `isspace()`; any byte ≥ 0x80 is UB / locale-dependent. **Fix:** cast to `unsigned char`: `isspace(static_cast<unsigned char>(str[i]))`.

## Acceptance
- `tryPop` drains the queue (consecutive pops return distinct elements).
- Malformed color string → rejected, no exception escapes.
- `monthDown` from January → December; `dayDown` commits the day; `getDayFromDate(7)` in-bounds; blank-line skip works.
- `Params` classification safe for high bytes.

## Verification
`make check` with unit tests for each: ThreadedQueue drain; malformed color inputs; Calendar month/day roll-over vectors; Params parsing of a high-byte string.
