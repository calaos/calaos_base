# T3.7 — ExternProc : kill de groupe de processus sur pid 0

**Type** : fix (critique) · **Phase** : 3
**Origine** : finding T3.2a, confirmé en revue (`src/bin/calaos_server/IO/ExternProc.cpp:100-104,120-121`).

## Problème
Après un `uv_spawn` raté, le pid du `ProcessHandle` reste 0. `~ExternProcServer` (et le
chemin de restart) fait `process_exe->kill(SIGTERM)` gardé seulement par `referenced()` →
`kill(0, SIGTERM)` = SIGTERM à **tout le groupe de processus** (a tué le harness de tests).

## Travail
Garder chaque `kill()` par `pid > 0` (les deux sites) ; test de régression si faisable sans
spawn réel (sinon lecture + commentaire de contrainte). Vérifier qu'aucun autre
`ProcessHandle::kill` du dépôt n'a le même défaut (grep) — corriger si dans ExternProc.cpp,
sinon reporter.

## Acceptation
Build + `make check` verts ; plus aucun `kill` non gardé dans ExternProc.cpp.
