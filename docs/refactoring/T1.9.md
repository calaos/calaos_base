## Constat

### F13 — mineur (boundary local) : bugs de framing
`ExternProcMessage::processFrameData` (`ExternProc.cpp:304-317`) teste `if (data.size() >= 3)` puis lit `data[0]..data[4]` (5 octets) et `data.erase(0,5)`. Avec 3-4 octets bufferisés, lecture **hors bornes** (`data[4]` OOB pour size 3).
- **Remédiation** : condition `>= 5`.

Autres points du même trust boundary (socket Unix local vers drivers spawnés) :
- `payload_length` est une valeur 32 bits **sans cap** ; `recv_buffer` bufferise jusqu'à réception → un sous-process compromis/défaillant peut épuiser la mémoire. Caper `payload_length`.
- `ExternProcClient::connectSocket` (`:428`) fait un `strcpy` dans `sockaddr_un.sun_path` sans borne 108 octets. Borner (`strncpy` + garantie de terminaison).

## Acceptance
- Test : buffer de 3-4 octets → pas de lecture OOB (condition `>= 5`).
- `payload_length` démesuré → rejeté sans allocation non bornée.
- Chemin de socket > 108 octets → tronqué proprement / erreur, pas de débordement.
