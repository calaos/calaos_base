# T3.173 — la sonde statique qui refusera le 46ᵉ `resource<>()` non regardé

**Statut** : 📋 · **Type** : fix · **Phase** : 3
**Origine** : [T3.141](T3.141.md) §5 — la moitié tree-wide que la livraison a délibérément laissée.

---

## 1. Ce qui reste ouvert

`T3.141` a fermé le seul site atteignable (`UrlDownloader.cpp`, `uv_poll_init_socket`). Les
**44 autres** restent non gardés, et c'est le bon choix : aucun de leurs initialiseurs ne peut
échouer aujourd'hui (recensement mesuré dans `T3.141` §2). ⛔ **« Aujourd'hui » est toute la
fragilité.** Trois façons de rouvrir le trou sans rien casser de visible :

1. Ajouter un 46ᵉ site avec un type dont l'initialiseur peut échouer — `PollHandle` est le seul
   d'aujourd'hui, il n'a pas à être le seul de demain.
2. Passer un site `TcpHandle`/`UDPHandle` de la forme sans drapeau à `uv_tcp_init_ex` /
   `uv_udp_init_ex` avec une vraie famille : une socket est alors créée, et `EMFILE` devient
   possible. Le site est **au même endroit**, la ligne a l'air identique.
3. Mettre à jour libuv vers une version dont un initialiseur aujourd'hui infaillible cesse de
   l'être.

Aucune revue ne rattrape ça à la lecture : la ligne fautive ressemble aux 44 qui vont bien.

## 2. Ce qui est demandé

Un recensement statique, sur le modèle de `SourceCensus::weighedOneShotSites()`
(`tests/core/IoLifetimeTimer_test.cpp`) qui tient déjà exactement cette forme pour
`Timer::singleShot()` / `Idler::singleIdler()` :

- compter, par fichier, les `resource<...>()` dont le retour est **déréférencé sans avoir été
  regardé** ;
- comparer à une table `fichier → compte` **portant la raison de chaque entrée** ;
- rougir sur tout compte supérieur, c'est-à-dire sur tout site neuf.

⚠️ **Pas 44 gardes mortes** : la table dit une fois ce que chaque revue redémontrerait sinon.
⭐ Le scanner doit porter son propre auto-test (« il compte des appels, pas de la prose ») : les
sondes de `tests/` qui n'en ont pas sont vertes parce qu'elles ne lisent rien.

## 3. Pourquoi elle n'est pas dans T3.141

Une table `fichier → compte` couvrant `src/bin/calaos_server/` et `src/lib/` entre en conflit avec
tout ticket concurrent qui ajoute ou déplace un `resource<>()` — `T3.142` travaillait sur
`UDPServer.cpp` (2 sites) dans la même vague. Elle se livre **seule**, hors fenêtre de vague.

## 4. Le Nu

⛔ Une sonde statique ne voit pas un `resource<>()` construit par macro ou par gabarit indirect, et
elle ne dira jamais si l'initialiseur d'un type **peut** échouer : elle tient un compte, pas une
preuve.
