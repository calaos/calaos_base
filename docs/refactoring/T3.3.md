## New findings (audit, English)

- **major/error-handling** `IPCam/SynoSurveillanceStation.cpp:188` — the non-jpeg branch `if (headers["Content-Type"] != "image/jpeg") { cWarning()…; cb({}); }` has **no `return`**, then `cb(data)` runs unconditionally → the snapshot completion callback fires **twice** on an error/JSON body, double-running the handler and corrupting `isRunning`/`lastSnapshot`. **Fix:** add `return;` after `cb({})`.
- **minor/security** `IPCam/Foscam.cpp:50,61,97,107` — credentials `&usr=…&pwd=…` in URLs on plain HTTP, logged (the original ticket cited `:50,61,97`; a **4th** occurrence at `:107` in `urlStop` was missed). **Fix:** mask credentials before `cDebugDom` at all four sites.
